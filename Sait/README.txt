CREATE SMC — ИНСТРУКЦИЯ
=========================

1. КАК ОТКРЫТЬ САЙТ
-------------------
- Зайдите в папку Sait.
- Дважды кликните по файлу index.html — сайт откроется в браузере.
- Интернет нужен для шрифтов Google Fonts (Montserrat + Inter).
- Для публикации в интернете — залейте всю папку Sait на любой хостинг.

2. КАРТИНКИ (уже добавлены)
---------------------------
Все картинки лежат в папке: Sait/img/

- img/avatar.png — аватарка сервера (логотип в шапке + иконка вкладки).
- img/logo.png   — копия аватарки (запасной вариант, тоже работает).
- img/banner.png — банер (широкая картинка вверху первого экрана).
- img/steve.png  — стив (блок "Как начать играть").
- img/skin.png   — копия стива (запасной вариант).
- img/cube.png   — красный куб (если добавишь, покажется справа;
                   пока его нет — там автоматически показывается аватарка).

Хочешь заменить картинку — просто положи новый файл с тем же именем в img/.
